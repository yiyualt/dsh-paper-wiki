# 互动图解的组织与自编示例

## 对照参考页时复用什么

复用其固定案例与紧凑说明的关系：

1. 顶部标题提出实际研究问题，一句话交代方法与结论，横向目录定位问题。
2. 左侧常驻案例窗约占可用宽度三分之一。阶段按钮、文件标签、带行号代码和短解释使用同一份状态；读者始终能找到正在讲的输入对象。
3. 右侧各节主要是任务输入输出、基线/方法对照、关系/流程、指标计算和结果图。图的说明附在相应对象附近，复杂细节可以展开，不在初始阅读面重复全部解释。
4. 选择或参数改变后，相关集合、数值或图形真实更新。真实实验数据不随教学参数改写。

卡片边框、代码框和表格本身不是可视化效果。需要看到具体对象、状态、依赖或数值发生了什么变化；不使用无对象的模块名流程。

## CSS 视觉约定

模仿这一类参考时，保留这些具体样式，而不只是给页面添加卡片：

- 浅色画布 `#f5f6fa`，白色章节，边线 `#e4e7f0`；紫色强调 `#4f46e5`，浅紫选中态 `#eef0ff`。
- 深色案例窗 `#172325`，窗口栏与解释区 `#1b2b2e`，边线 `#293638`；键名浅蓝、字符串浅绿、数值浅橙。选中代码行用 `#24403d` 与薄荷色左边线 `#68cdb6`，不只改变文字颜色。
- 桌面布局左列约430px、列间24px；章节22–24px内边距、12px圆角和很浅的阴影。正文14px、图注/表格11–12px、章节标题19px，避免把所有文字放成同一字号。
- 案例窗使用等宽字、行号、阶段按钮、文件标签和单行解释高亮；局部代码滚动，解释区保留可见。详细定义折叠，不靠缩小整页字号减少篇幅。
- 绿色表示满足条件、琥珀色表示缺失或注意、红色表示违反约束。表格保留必要数字，用热度或迷你数值条帮助比较；条形图高度约14px。色彩和长度须与实际状态、数值一致。

应用内直接使用固定模板的 CSS；独立 HTML 输出应将对应样式嵌入成品，离线打开仍保留完整外观。

## 同一商品查询的小案例

以下是自行构造的教学资料；只有目标论文确实使用对应机制，才能映射为该论文的讲解。

任务：给定查询标题及带 ID 的商品列表，输出首个精确匹配的商品 ID，没有匹配时输出 null。

常驻窗保存三个阶段：

```json
{
  "query": "PHONE",
  "products": [{"id": "p1", "title": "phone"}]
}
```

点 query 行只需解释「要匹配的标题是大写 PHONE」；点 products 行解释「候选 p1 的标题为小写 phone，成功时返回 p1」。不在同一行旁再展开字符串、ID、数据列表的多段百科定义。

基线阶段展示 `PHONE != phone → null`。作者方法阶段展示 `lower(PHONE) = lower(phone) → p1`。右侧两列对照可只显示：

| 直接比较 | 双方转小写后比较 |
| --- | --- |
| PHONE ≠ phone | phone = phone |
| 没有匹配 → null | 标题相同 → p1 |

图后的短结论：「不足发生在大小写敏感的比较；转换只解决大小写差异，不解决不同词语的同义表达。」代码输入不在右栏重新完整展开。

术语「归一化」的常驻短定义是「把不同写法转成共同形式」；本例微例为 `PHONE → phone`。展开后再说明它不等于语义理解，并保留原文支持的适用范围。只给理解当前操作必需的几个术语。

## 让图承担说明

| 要回答的问题 | 内容形式 | 应显示的具体内容 |
| --- | --- | --- |
| 输入输出是什么？ | 输入 → 处理 → 输出 | 查询 PHONE、候选 p1/phone、输出 p1 |
| 改了哪一步？ | 基线/方法对照 | 比较前是否做 lower，结果 null/p1 |
| 对象怎样对应？ | 有向关系图 | 原标题、转换后的标题、原商品 ID；边说明转换或返回 |
| 数值怎么得到？ | 给定计数的可调计算 | 正确数 / 总数 × 100；明确只重算公式，不重跑实验 |
| 实验支持什么？ | 真实结果图 + 短结论 | 相同条件、指标、单位、原始值和各点来源 |

图和代码共用对象名称与阶段。关系图只需展示这个问题必需的节点，不把论文所有组件画在一图。预算或集合对照应让读者直接看到增加/移除的对象，不靠长说明猜测变化。

## 输出与核验

应用内任务按 [app-contract.md](app-contract.md) 输出。独立 HTML 可用相同的两栏骨架和可信交互代码。使用语义换行、局部代码滚动和可键盘操作的按钮；窄屏不要造成整页横向溢出。

所有阶段、数据和细节都在成品里，但初始只展示当前阶段与短解释；打印或完整导出保留全部资料。离线 HTML 不依赖 CDN、联网 API 或外部模型。构造变量的范围、公式及更新结果一致，论文观测只读。交付前实际切阶段、点行、改变参数并检查显示结果。
